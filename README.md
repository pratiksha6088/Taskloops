# Task 14: JavaScript – Loops

## Description

This project is created as part of the TuteDude JavaScript Loops task.

The program performs different operations on a given number using JavaScript loops and displays the results on the webpage.

## 🎯 Objective

The objective of this task is to create a JavaScript program that:

* Finds the sum of digits of a number.
* Counts the number of digits.
* Checks whether the number is a Prime number.
* Prints all factors of the number.
* Checks whether the number is an Armstrong number.
* Uses different variables for different operations.
* Displays the results using `console.log()` and on the webpage.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🔄 Loops Used

### 1. For Loop

Used for:

* Counting digits
* Checking Prime number
* Finding factors

### 2. While Loop

Used for:

* Finding the sum of digits
* Checking Armstrong number

### 3. Do-While Loop

Used to demonstrate the execution of a do-while loop.

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a number in the input box.
5. Click the **Check Number** button.
6. The result will be displayed on the webpage.
7. Open the browser Developer Console to see the `console.log()` output.

## 🧪 Example

For input:

```text
153
```

Output:

```text
Number: 153
Number of digits: 3
Sum of its digits: 9
Is it an Armstrong number? Yes
Is it a Prime number? No
Factors: 1, 3, 9, 17, 51, 153
```
